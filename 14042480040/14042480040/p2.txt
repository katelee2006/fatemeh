

## سؤال : Class چیست؟
یه قالب شیرینی داری. قالب خودش شیرینی نیست، فقط شکل و اندازه رو مشخص می‌کنه.
Classهم همین‌طوریه کلاس یک الگو یا نقشه است که ویژگی‌ها (Property) و رفتارهای (Method) یک نوع موجودیت را تعریف می‌کند. کاربردش این است که کد را منظم می‌کند و به‌جای نوشتن چندباره‌ی یک چیز، از روی یک الگو چندین نمونه می‌سازیم.
## سؤال ۲: Object چیست؟
Object همون شیرینی‌ای است که از قالب درآوردی. یعنی یه نمونه‌ی واقعی و مشخص که از روی Class ساخته شده. از یک قالب می‌تونی صدها شیرینی بسازی، و هر کدوم می‌تونه رنگ و تزئین خودش رو داشته باشه.
Student s1 = new Student("Ali", 1234);   // یک Object
Student s2 = new Student("Sara", 5678);  // یک Object دیگه
آبجکت یک نمونه‌ی واقعی است که از روی کلاس ساخته می‌شود و مقادیر مخصوص خودش را دارد. رابطه‌شان این است که کلاس طرح کلی است و آبجکت محصول ساخته‌شده از آن طرح؛ از یک کلاس می‌شود چندین آبجکت ساخت.
## سؤال ۳: Property چیست؟
Property یعنی ویژگی یا اطلاعاتی که یه Object داره. توی مثال شیرینی، رنگ، مزه و وزنش Property هستن.
برای Student مثلاً: نام، شماره دانشجویی و رشته.
public string Name { get; set; }
public int StudentNumber { get; set; }
public string Major { get; set; }
پراپرتی یک ویژگی یا داده‌ی مربوط به آبجکت است که اطلاعات آن را نگه می‌دارد، مثل نام یا سن. کاربردش ذخیره و خواندن (و در صورت نیاز تغییر) اطلاعات آبجکت است.
## سؤال ۴: Method چیست؟

Method یعنی کاری که یه Object می‌تونه انجام بده. یعنی یه تکه کد که اسم داره و هر وقت صداش بزنی اجرا می‌شه. برای Student: درس خوندن و محاسبه‌ی معدل.
public void Study()
{
    Console.WriteLine(Name + " is studying");
}
یک بلوک کد نام‌دار است که یک رفتار یا عمل را برای آبجکت انجام می‌دهد. کاربردش جلوگیری از تکرار کد و سازمان‌دهی کارهایی است که آبجکت می‌تواند انجام دهد.
سؤال ۵: Constructor چیست؟
Constructor یه متد مخصوصه که همون لحظه‌ی ساخته شدن Object خودکار اجرا می‌شه و مقدار اولیه‌ی Propertyها رو می‌ذاره. مثل وقتی که ماشین رو می‌سازن و همون موقع رنگش رو مشخص می‌کنن.
public Student(string name, int number)
{
    Name = name;
    StudentNumber = number;
}
وقتی می‌نویسی new Student("Ali", 1234) همین Constructor اجرا می‌شه.
کانستراکتور یک متد خاص هم‌نام با کلاس است که بدون نوع بازگشتی تعریف می‌شود. هنگام ساخت آبجکت با کلمه‌ی new به‌صورت خودکار اجرا می‌شود و کارش مقداردهی اولیه به پراپرتی‌هاست.
سؤال ۶: تفاوت Class و Object (با مثال واقعی)
مثال ماشین:
Class = نقشه‌ی ماشین، که فقط می‌گه ماشین رنگ، برند و سرعت داره. خودش ماشین واقعی نیست.
Object = ماشین‌های واقعی‌ای که از روی اون نقشه ساخته می‌شن، مثل پراید سفید و پژو مشکی.
کلاس تعریف و طرح کلی است و فضای داده‌ی واقعی ندارد، ولی آبجکت نمونه‌ی واقعی و ساخته‌شده از کلاس است و مقادیر خودش را دارد. مثلاً کلاس Car نقشه است و هر ماشین مشخص یک آبجکت.

## سؤال ۷: تفاوت Constructor و Method
Constructor:
- اسمش دقیقاً هم‌نام کلاسه
- نوع بازگشتی نداره (حتی void هم نمی‌نویسی)
- خودکار و فقط یک بار، موقع ساخت Object با new اجرا می‌شه
- کارش مقداردهی اولیه‌ی Propertyهاست
Method:
- هر اسمی می‌تونه داشته باشه
- نوع بازگشتی داره (void، int، string و...)
- دستی صدا زده می‌شه و هر چند بار که بخوای اجرا می‌شه
- کارش انجام یه عمل یا رفتاره
آیا یک Class می‌تونه چند Constructor داشته باشه؟ بله، به شرطی که ورودی‌هاشون فرق کنه (تعداد یا نوع پارامتر). بهش می‌گن Overloading:
public Student(string name) { Name = name; }
public Student(string name, int number)
{
    Name = name;
    StudentNumber = number;
}
حالا می‌شه هم new Student("Ali") نوشت، هم new Student("Ali", 1234).
8آیا یک Class می‌تواند چند Constructor داشته باشد؟
با مثال توضیح دهید.
بله، یک کلاس می‌تونه چند Constructor داشته باشه، به شرطی که پارامترهاشون از نظر تعداد یا نوع با هم فرق داشته باشه. به این کار می‌گن Overloading.
public class Student
{
    public string Name { get; set; }
    public int StudentNumber { get; set; }

    // Constructor ۱: فقط اسم
    public Student(string name)
    {
        Name = name;
    }
    // Constructor ۲: اسم و شماره دانشجویی
    public Student(string name, int number)
    {
        Name = name;
        StudentNumber = number;
    }
}
موقع ساخت Object، C# خودش از روی ورودی‌ها می‌فهمه کدوم Constructor رو اجرا کنه:
Student s1 = new Student("Ali");          // Constructor ۱
Student s2 = new Student("Sara", 5678);   // Constructor ۲
یک کلاس می‌تواند چند کانستراکتور داشته باشد، به شرط اینکه لیست پارامترهایشان (تعداد یا نوع) با هم متفاوت باشد. به این قابلیت Constructor Overloading می‌گویند. کاربردش این است که بتوانیم آبجکت را به روش‌های مختلف بسازیم، مثلاً گاهی فقط با نام و گاهی با نام و شماره دانشجویی. در مثال بالا، کلاس Student دو کانستراکتور دارد و بسته به ورودی، یکی از آن‌ها اجرا می‌شود.
## سؤال  9 : Status Code چیست؟
Status Code یه عدد سه‌رقمیه که سرور تو Response می‌فرسته تا بگه درخواست چی شد: موفق بود، خطا داشت و...
- 200 (OK): درخواست موفق بود و اطلاعات درست برگشت.
- 201 (Created): یه چیز جدید با موفقیت ساخته شد، مثلاً ثبت‌نام یا اضافه کردن محصول.
- 400 (Bad Request): درخواست اشتباه بود، مثلاً اطلاعات ناقص یا نامعتبر فرستادی.
- 401 (Unauthorized): هویتت مشخص نیست، مثلاً لاگین نکردی.
- 403 (Forbidden): لاگین کردی ولی اجازه‌ی دسترسی نداری، مثلاً کاربر عادی رفته صفحه‌ی ادمین.
- 404 (Not Found): چیزی که خواستی پیدا نشد، مثلاً آدرس یا محصول وجود نداره.
- 500 (Internal Server Error): خطا تو خود سرور رخ داده، مثلاً باگ تو کد.
اولین رقم دسته‌ی کد رو می‌گه. 2xx یعنی موفق، 4xx یعنی اشتباه از سمت کاربر، 5xx یعنی اشتباه از سمت سرور.
سؤال ۹: Port چیست؟
پورت شماره‌ای است که مشخص می‌کند درخواست به کدام برنامه روی سیستم برسد. چون روی یک سرور چند برنامه می‌تواند اجرا شود، پورت مسیر درست را تعیین می‌کند. پورت پیش‌فرض http برابر 80 و https برابر 443 است.
⭐ سؤال چالشی: وقتی https://example.com/products/10 رو می‌زنی
مرحله‌به‌مرحله:
مرورگر آدرس رو می‌شکنه: https پروتکل، example.com آدرس سرور، /products/10 یعنی «محصول شماره‌ی ۱۰».
DNS: اسم example.com به آدرس IP سرور تبدیل می‌شه.
اتصال به Port: چون https هست، مرورگر به پورت پیش‌فرض 443 سرور وصل می‌شه.
ارسال Request: مرورگر درخواست GET /products/10 رو می‌فرسته.
Routing: برنامه‌ی وب می‌بینه آدرس /products/10 مال کدوم کلاس و متد (مثلاً ProductsController) هست و عدد 10 رو به‌عنوان ورودی می‌گیره.
اجرای کد: از کلاس Product یه Object ساخته می‌شه، اطلاعات محصول 10 از دیتابیس خونده می‌شه و تو Propertyهاش (نام، قیمت و...) گذاشته می‌شه.
ساخت Response: سرور اطلاعات رو همراه با یه Status Code برمی‌گردونه.
نمایش: مرورگر اطلاعات رو به کاربر نشون می‌ده.
Status Codeها:
محصول پیدا شد → 200 OK
محصول وجود نداشت → 404 Not Found
خطا تو سرور → 500 Internal Server Error
نقش Port: مرورگر با Port مشخص می‌کنه درخواستش دقیقاً به کدوم برنامه‌ی روی سرور بره. برنامه‌ی وب پشت یه پورت (مثلاً 443) گوش می‌ده و بدون پورت درست، درخواست به برنامه نمی‌رسه.
